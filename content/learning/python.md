28 sessions, 45 to 60 minutes every second day. The goal is reviewer literacy: read a script an AI wrote, explain each line, and spot what is wrong. Each session is ticked only when there is a commit to show for it.

## Block 0 · Setup
- [ ] S1 · Install Python and VS Code; ten terminal commands; hello.py
- [ ] S2 · Git and GitHub: first repo, first commit, push

## Block 1 · Foundations
- [ ] S3 · Variables and data types: a position-size calculator
- [ ] S4 · Strings: split "Peraturan Pemerintah Nomor 28 Tahun 2025" into type, number and year
- [ ] S5 · Lists: sort regulations by year, take the three newest
- [ ] S6 · Dictionaries: look things up by name
- [ ] S7 · if / elif / else: classify text by keywords
- [ ] S8 · Loops: count regulations per sector
- [ ] S9 · Functions: turn sessions 4 to 8 into reusable functions
- [ ] S10 · Checkpoint 1, without AI: three problems, plus try / except

## Block 2 · Data and files

- [ ] S14 · JSON and nested dictionaries

- [ ] S16 · Regex: catching regulation numbers in free text
- [ ] S17 · Mini-project: text → parser → Excel summary, end to end
