A lesson I took from Indonesia's investing community: wealth eventually settles at the level of the value behind it. High value with little wealth is a gap that time tends to close; wealth without value tends to erode.

So the first investment is in the value itself: skills, knowledge, and work that holds up. The return does not arrive on a schedule ([[Sideways is still progress.]]).

The value also has to be real, not just reported: [[Follow the cash, not the story.]]
